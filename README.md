# Birthday Surprise 💖

A romantic, animated birthday website: envelope intro, falling petals, live age counter, photo gallery, flip cards, story timeline, blow-out-the-candles cake and a love letter.

## Personalise
Open `index.html` and edit the `CONFIG` block at the top of the script (name, birth date, messages, photos, music).
Drop photos in `photos/` (1.jpg … 6.jpg) and an optional song in `media/`.

## Host free
Settings → Pages → Deploy from branch `main` / root.
